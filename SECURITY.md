# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose user
data or weaken extension isolation. Use GitHub's private vulnerability reporting
for this repository. If that is unavailable, contact Wavect through the support
details at <https://wavect.io/tools/mcp-install-risk-scanner/#support>.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. Do not include real credentials or private configuration in a
report. Replace them with synthetic values.

## Supported versions

The latest tagged release receives security fixes. The scanner is static
analysis, not a malware verdict, sandbox, package reputation service, or proof
that an unflagged command is safe.
