# Privacy disclosure

MCP Install Risk Scanner processes selected or visible setup text locally in the
browser extension. It does not collect, transmit, sell, retain, or share user
data. It has no account system, analytics, advertising, remote rules, or server
processing.

The `activeTab` permission provides temporary access to the current tab only
after the user invokes the extension. The extension reads selected text or
visible `pre` and `code` elements for the requested scan. It does not read
browsing history or run on pages in the background.

Exports are created locally and downloaded only when the user clicks an export
button. Evidence is redacted before it enters the report.
