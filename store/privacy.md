# Privacy disclosure

MCP Install Risk Scanner handles selected or visible website content only to
perform the scan that the user explicitly requests. Processing happens locally
in the browser extension. The extension does not transmit, sell, retain, or
share user data. It has no account system, analytics, advertising, remote rules,
or server processing.

The `activeTab` permission provides temporary access to the current tab only
after the user invokes the extension. The extension reads selected text or
visible `pre` and `code` elements for the requested scan. It does not read
browsing history or run on pages in the background.

Exports are created locally and downloaded only when the user clicks an export
button. Evidence is redacted before it enters the report.

The use of information received through Chrome APIs adheres to the Chrome Web
Store User Data Policy, including the Limited Use requirements. Website content
is used only for the extension's single user-facing purpose. It is not used for
advertising, creditworthiness, unrelated features, or human review, and it is
not transferred to third parties.
