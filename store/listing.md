# Chrome Web Store listing

## Name

MCP Install Risk Scanner

## Single purpose

Statically inspect selected or visible MCP setup snippets for risk signals
without executing or uploading them.

## Short description

Review MCP install commands and config for risky patterns before you run them.

## Detailed description

MCP Install Risk Scanner highlights observable setup signals such as piped
shell execution, elevated privileges, destructive commands, sensitive paths,
embedded credentials, unpinned runners, insecure endpoints, broad environment
access, and privileged containers.

Select a command on a page and use the context menu, or open the extension and
scan selected or visible setup text. Findings include redacted evidence,
remediation, and links to the methodology. Export a report as JSON or Markdown
when you need review evidence.

All analysis happens locally in the extension. There is no account, upload,
telemetry, remote code, or fetched rule set. A result with no flagged patterns
is not proof that a package or server is safe.
